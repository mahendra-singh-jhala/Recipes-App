# 🍲 Recipe App Backend

This is the backend for a **Recipe App** that allows users to manage their recipes efficiently. It supports full **CRUD operations**—Create, Read, Update, and Delete—on recipe data via a RESTful API.

## 🚀 Features

- Create new recipes with relevant details.
- Retrieve a list of all recipes or a specific one by ID.
- Update recipe details.
- Delete recipes no longer needed.
- RESTful API endpoints using modern backend stack.

## 🛠️ Technologies Used

- **Node.js**
- **Express.js**
- **MongoDB** with **Mongoose**
- **JWT** for authentication 
- **dotenv** for environment variable management

## 🚀 Getting Started

1. **Clone the repository:**

```bash
 git clone https://github.com/mahendra-singh-jhala/Recipes-App
```

2. **Install dependencies**

```bash
 npm install
```

3. **Run the backend server**

```bash
 npm run dev
```
